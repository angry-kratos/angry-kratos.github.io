# angry-kratos.github.io

Source for [angry-kratos.github.io](https://angry-kratos.github.io), built with [Quarto](https://quarto.org).

- `posts/<slug>/index.qmd`: one folder per post, figures next to it
- `code/<slug>/`: the code and scripts behind each post
- Pushing to `main` renders and deploys via GitHub Actions (`.github/workflows/publish.yml`)

Local preview: `quarto preview`
